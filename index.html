Find teammates without leaving Discord.

LFG Bot is a self-hosted Discord bot for one League of Legends community server. It turns looking-for-group posts into teams and voice channels, shows members' ranks on a server leaderboard, and lets members follow professional players' ranked games.

It runs on a single server and is not a public bot. Its replies are in Simplified Chinese.

Features

The Riot API is used only by the two opt-in features on the right. Finding a group works without it.

Looking for group

Post a message such as LOL 4=1 or 4缺1. The bot works out how many players the group still needs, tracks open slots as people join, and creates a temporary voice channel for the group that is removed once it's empty.

No Riot API

Rank linking & leaderboard

Members link their own Riot account and prove they own it with a profile icon check. Linked members appear on a server leaderboard sorted by Solo/Duo rank, posted every 12 hours.

Account-v1 · Summoner-v4 · League-v4

Pro player tracker

Members choose professional players to follow. The bot posts in the channel where tracking was turned on when a followed pro starts or finishes a ranked Solo/Duo game, with the champion, start time and game length.

Account-v1 · Spectator-v5

How we use the Riot API

These are the only Riot API endpoints the bot calls.

APIEndpointUsed forHow often
Account-v1 /riot/account/v1/accounts/by-riot-id/{gameName}/{tagLine} Look up the PUUID when a member links an account, or when a pro account is first tracked Once per account
Account-v1 /riot/account/v1/accounts/by-puuid/{puuid} Keep linked Riot IDs current after a name change Every 30 minutes per verified account
Summoner-v4 /lol/summoner/v4/summoners/by-puuid/{puuid} Read the profile icon to confirm the member owns the account When a member links and verifies an account
League-v4 /lol/league/v4/entries/by-puuid/{puuid} Read Solo/Duo tier, division, LP, wins and losses for the leaderboard Every 30 minutes per verified account
Spectator-v5 /lol/spectator/v5/active-games/by-summoner/{puuid} Check whether a followed pro is in a ranked Solo/Duo game About every 20 seconds per followed pro account

All requests go through one client with a client-side rate limiter. Champion names come from Data Dragon's static data.

Linking your account

Linking is optional. Only the account owner can link it.

  1. Run /rank bind riot_id:Name#TAG in the server.
  2. The bot shows one of the default profile icons. Set it as your profile icon in the League client.
  3. Run /rank verify riot_id:Name#TAG within 10 minutes. The bot checks your icon and links the account. Requests that are not verified in time are deleted.
  4. Change your icon back whenever you like. Run /rank unbind at any time to remove the link and its rank data.

Data we store

Everything is kept in the bot's own database on the server that hosts it.

Linked accounts

  • Discord user ID
  • Riot ID and PUUID
  • Solo/Duo tier, division, LP, wins and losses

Deleted when you run /rank unbind.

Pro tracker

  • Player name, team, Riot ID and PUUID of each listed pro account
  • The channel to post in, and who turned tracking on
  • The tracked player's current game ID, champion and start time, so the bot can announce when it ends

We don't store match history or anything about the other players in a game.

Commands

Slash commands for the Riot API features.

CommandWhat it does

/rank meShow your linked accounts and rank
/rank list [limit]Show the server leaderboard
/trackpro add targetFollow a pro by player name (all their accounts) or Riot ID
/trackpro remove targetStop following a pro
/trackpro listShow followed pros and whether they're in a game
/trackpro prosShow the pro player list
