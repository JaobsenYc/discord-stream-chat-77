# LOL 内鬼局功能

## 功能概述

内鬼局是一个特殊的LOL内战玩法，在传统的5v5对战基础上增加了隐藏角色元素。每个队伍会有1-4个"内鬼"，他们的目标是在不被发现的情况下让自己的队伍输掉比赛。

## 使用方法

### 创建内鬼局

使用以下命令创建内鬼局：

```
/lol start type:custom name:王者大师内鬼局 spy:yes spy_num:2
```

**参数说明：**
- `type`: 比赛类型，目前只支持 `custom`
- `name`: 内战名称（可选），如果不填写则使用默认名称"LOL内鬼局"
- `spy`: 是否开启内鬼模式，设置为 `yes` 或 `true`
- `spy_num`: 每队内鬼数量，范围1-4，默认为1

### 参与内鬼局

1. 点击机器人发布的招募消息中的"参与"按钮
2. 达到10人后自动开始分组
3. 内鬼会收到私信通知，告知他们的特殊身份

## 内鬼规则

### 内鬼任务
- **目标**：在不被发现的情况下让自己的队伍输掉比赛
- **方式**：适度地影响团战决策、资源分配等，但不能太明显
- **禁止**：明显的送人头、故意挂机等过于明显的行为

### 保密要求
- 内鬼身份绝对保密，不得向任何人透露
- 收到私信通知后，请及时查看任务说明
- 比赛结束后会有投票环节猜测内鬼身份

## 游戏流程

1. **创建阶段**：使用slash命令创建内鬼局
2. **招募阶段**：玩家点击按钮参与，显示当前人数和内鬼模式信息
3. **分组阶段**：达到10人后自动随机分组为蓝红两队
4. **内鬼选择**：系统自动从每队随机选择指定数量的内鬼
5. **私信通知**：内鬼收到包含任务说明的私信
6. **游戏开始**：创建语音频道，开始对战

## 显示特色

### 招募消息特色
- 🕵️ 使用特殊的间谍表情符号
- 显示"内鬼局招募中"标题
- 额外显示每队内鬼数量信息
- 招募描述中说明这是内鬼局

### 分组结果特色
- 🕵️ 特殊的分组完成标题
- 说明内鬼已被选择并私信通知
- 添加内鬼提示信息，解释游戏规则
- 提醒比赛结束后有投票环节

## 内鬼私信内容

内鬼会收到包含以下信息的私信：

```
🕵️ 内鬼任务

您在内战 [内战名称] 中被选为 [队伍颜色] 的内鬼！

🎯 任务目标
在不被发现的情况下，让您的队伍输掉比赛

⚠️ 注意事项
• 不要太明显地送人头或做出异常行为
• 适度地影响团战和决策
• 比赛结束后会有投票环节

🤫 保密
请勿向任何人透露您的内鬼身份！
```

## 配置要求

确保`.env`文件中已正确配置：

```bash
# LOL内战基础功能必须启用
LOL_CUSTOM_ENABLED=true
LOL_CUSTOM_CHANNEL_IDS=your_channel_id_here
LOL_CUSTOM_CATEGORY_ID=your_category_id_here
```

## 注意事项

1. **权限要求**：机器人需要有发送私信的权限
2. **用户DM设置**：参与者需要允许服务器成员发送私信
3. **随机性**：内鬼选择完全随机，无法人工指定
4. **数量限制**：每队最多4个内鬼，避免游戏失去平衡
5. **故障处理**：如果私信发送失败，不影响游戏继续进行

## 技术实现

- 使用Fisher-Yates洗牌算法确保随机性
- 异步发送私信，避免阻塞游戏流程
- 内鬼身份信息安全存储，不在公开消息中显示
- 支持并发处理多个内鬼局
