# 🎮 LOL比赛竞猜系统使用指南

## 📖 功能概述

LOL比赛竞猜系统允许用户在语音频道中发起比赛竞猜，其他用户可以使用积分下注预测比赛结果。

### 核心特性
- 🎯 **语音频道发起**: 必须在活跃的语音频道中发起竞猜
- 💰 **积分下注**: 使用10-1000积分下注
- 📊 **博彩盘口**: 赢家按比例分配输家的全部积分
- 🔒 **手动控制**: 发起人控制比赛开始和结果公布
- ⏰ **自动过期**: 24小时未锁定自动退款
- 🗑️ **频道监控**: 语音频道删除自动取消竞猜

---

## 🚀 使用方法

### 1. 发起竞猜

**前提条件**:
- 你必须在一个语音频道中
- 该语音频道没有其他活跃的竞猜

**命令**:
```
/bet create <team_a> <team_b> [name]
```

**参数说明**:
- `team_a`: 队伍A的名称（如："SKT"）
- `team_b`: 队伍B的名称（如："T1"）
- `name`: 竞猜名称，可选（如："春季赛决赛"）

**示例**:
```
/bet create SKT T1
/bet create 蓝队 红队 内战竞猜
/bet create IG JDG 春季赛决赛
```

**结果**:
Bot会发送一条竞猜消息，包含：
- 📊 当前下注情况（两队总下注额和人数）
- 📈 实时赔率预估
- 🔵🔴 下注按钮
- 🔒 开始比赛按钮（仅发起人可用）
- ❌ 取消竞猜按钮（仅发起人可用）

---

### 2. 参与下注

**步骤**:
1. 点击竞猜消息下方的 **🔵 下注 队伍A** 或 **🔴 下注 队伍B** 按钮
2. 在弹出的模态框中输入下注金额（10-1000积分）
3. 点击提交

**限制**:
- 每人只能对一个竞猜下注一次
- 下注金额必须在10-1000积分之间
- 必须有足够的可用积分

**成功后**:
- 系统会扣除你的积分
- 竞猜消息会实时更新显示最新的下注情况和赔率
- 你会收到预估收益提示

---

### 3. 开始比赛（锁定下注）

**权限**: 仅发起人可以操作

**操作**: 点击 **🔒 开始比赛** 按钮

**条件**:
- 必须至少有1个人下注
- 两队都必须有人下注

**效果**:
- 下注按钮消失，无法继续下注
- 显示结算按钮：**🏆 队伍A获胜** 和 **🏆 队伍B获胜**

---

### 4. 公布结果

**权限**: 仅发起人可以操作

**操作**:
- 点击 **🏆 队伍A获胜** 或 **🏆 队伍B获胜** 按钮

**效果**:
- 系统自动计算并发放积分给获胜方
- 竞猜消息更新为结算状态
- 显示：
  - 🏆 获胜队伍
  - 🎉 所有获胜者名单
  - 💰 总奖池金额
  - 👥 总参与人数

---

### 5. 取消竞猜

**权限**: 仅发起人可以操作

**操作**: 点击 **❌ 取消竞猜** 按钮

**效果**:
- 所有参与者的积分全额退还
- 竞猜状态变为"已取消"

**自动取消情况**:
- 24小时未锁定比赛
- 语音频道被删除

---

### 6. 查看竞猜列表

**命令**:
```
/bet list
```

**显示内容**:
- 当前服务器所有活跃的竞猜
- 每个竞猜的状态（下注中/已锁定）
- 两队的下注情况
- 创建者信息

## 💰 收益计算规则

### 博彩盘口算法

**基本原则**: 赢家按比例分配输家的全部积分（无手续费）

**计算公式**:
```
总奖池 = 获胜方总下注 + 失败方总下注
每个获胜者的收益 = 总奖池 × (该用户下注额 / 获胜方总下注额)
```

### 示例计算

**场景**:
- **A队下注**: 1000积分
  - 用户1: 500积分
  - 用户2: 300积分
  - 用户3: 200积分
- **B队下注**: 500积分
  - 用户4: 300积分
  - 用户5: 200积分

**假设A队获胜**:
- 总奖池 = 1000 + 500 = 1500积分
- 用户1获得: 1500 × (500/1000) = **750积分** (收益250)
- 用户2获得: 1500 × (300/1000) = **450积分** (收益150)
- 用户3获得: 1500 × (200/1000) = **300积分** (收益100)
- 用户4损失: 300积分
- 用户5损失: 200积分

**赔率显示**:
- A队赔率: 1:1.50（即下注100能得150）
- B队赔率: 1:3.00（即下注100能得300）

## ⚠️ 注意事项

### 发起竞猜
1. **必须在语音频道中**: 无法在文字频道单独发起
2. **一个频道一个竞猜**: 同一语音频道只能有一个活跃竞猜
3. **24小时有效期**: 超时未锁定会自动退款

### 下注限制
1. **一人一次**: 每人只能对一个竞猜下注一次
2. **金额范围**: 10-1000积分
3. **积分充足**: 必须有足够的可用积分

### 比赛控制
1. **发起人权限**: 只有发起人可以锁定比赛和公布结果
2. **两队下注**: 锁定前两队都必须有人下注
3. **诚信原则**: 请诚实公布比赛结果

### 频道监控
1. **自动取消**: 语音频道删除后竞猜自动取消并退款
2. **实时更新**: 下注信息实时更新显示

## 🚨 常见问题

**Q: 点击下注按钮没反应？**
A: 检查你是否有足够的积分，或者是否已经下注过。

**Q: 如何获得积分？**
A: 使用 `/checkin daily` 每日签到、参与抽奖、完成成就等方式获取。

**Q: 能修改已下注的金额吗？**
A: 不能，每人每次竞猜只能下注一次。

**Q: 发起人可以参与下注吗？**
A: 可以，发起人也可以下注。

**Q: 赔率是固定的吗？**
A: 不是，赔率会随着下注情况实时变化。

**Q: 如果没人下注某一队怎么办？**
A: 无法锁定比赛，必须两队都有人下注才能开始。

**Q: 比赛中途可以取消竞猜吗？**
A: 锁定后只能公布结果或取消，取消会退还所有积分。

**Q: 24小时后会怎样？**
A: 系统会自动取消竞猜并退还所有积分。

**Q: 如果发起人不公布结果怎么办？**
A: 24小时后会自动过期退款，或联系管理员处理。

**Q: 收益是立即到账吗？**
A: 是的，点击结算后立即发放到获胜者账户。
