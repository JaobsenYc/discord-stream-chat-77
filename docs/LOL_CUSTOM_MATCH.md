# LOL 内战系统使用指南

## 📖 功能概述

LOL内战系统是一个专门为英雄联盟玩家设计的5v5自定义比赛组织功能。通过简单的Slash命令和按钮交互，玩家可以快速发起内战、招募队友、自动分组并创建专用语音频道。

## ✨ 主要特性

- 🎮 **一键发起**: 使用 `/lol start custom` 命令快速发起内战
- 👥 **按钮报名**: 点击按钮即可参与或离开内战
- 🎲 **随机分组**: 满员后自动随机分配蓝红两队
- 🎵 **语音频道**: 自动为两队创建专用语音频道
- 👑 **队长系统**: 每队自动指定队长
- 🕒 **自动清理**: 内战结束后自动清理语音频道

## 🚀 使用方法

### 1. 发起内战

在指定频道中使用Slash命令：

```
/lol start custom
```

机器人会发布一条内战招募消息，包含：
- 当前参与人数 (x/10)
- 创建时间
- 参与者列表
- 三个操作按钮

### 2. 参与内战

点击 **🎮 参与内战** 按钮即可加入队伍。

**限制**：
- 每人同时只能参与一个内战
- 满10人后自动开始分组

### 3. 离开内战

如果还未开始分组，可以点击 **❌ 离开** 按钮退出。

**注意**：
- 内战开始后无法离开
- 如果创建者离开，内战会被取消

### 4. 取消内战

创建者可以点击 **🚫 取消内战** 按钮取消内战。

## 🎯 自动分组流程

当参与人数达到10人时，系统会：

1. **随机分组**: 使用Fisher-Yates算法公平分配
2. **指定队长**: 每队第一位成员自动成为队长👑
3. **创建频道**: 自动创建两个语音频道
   - 🔵 LOL内战 - 蓝队 [内战ID]
   - 🔴 LOL内战 - 红队 [内战ID]
4. **发送通知**: @所有参与者并显示分组结果
5. **更新消息**: 显示最终分组信息和语音频道链接

## ⚙️ 配置说明

### 环境变量配置

确保以下配置项正确设置：

```env
# Discord基础配置
DISCORD_TOKEN=你的机器人Token
GUILD_ID=你的服务器ID

# 语音频道配置
DEFAULT_CATEGORY_ID=语音频道分类ID
```

### 权限要求

机器人需要以下权限：
- ✅ 发送消息
- ✅ 使用Slash命令
- ✅ 管理频道（创建/删除语音频道）
- ✅ 查看频道
- ✅ 提及所有人

## 🔧 管理功能

### 手动完成内战

管理员可以通过代码手动完成内战：

```go
// 获取内战管理器实例
err := bot.lolManager.CompleteMatch(matchID)
```

### 清理语音频道

系统会在内战结束30分钟后自动清理语音频道。

## 🚨 故障排除

### 常见问题

**Q: 点击按钮没有反应？**
A: 检查机器人权限，确保有发送消息和使用Slash命令的权限。

**Q: 没有创建语音频道？**
A: 检查机器人是否有"管理频道"权限，以及语音分类ID是否正确配置。

**Q: 内战卡住无法继续？**
A: 联系管理员手动完成或重启机器人。

**Q: 分组不公平？**
A: 系统使用标准的Fisher-Yates洗牌算法，确保完全随机分配。

### 日志调试

- `用户 [userID] 加入内战 [matchID]`
- `内战 [matchID] 开始，蓝队: [...], 红队: [...]`
