# 游戏分类设置指南

## 概述

机器人为不同游戏创建的临时语音频道会归入各自的 Discord 分类,让服务器整洁有序。
游戏与频道的对应关系**只**由 `.env` 中的 `CHANNEL_MAPPINGS` 环境变量决定。

> 历史文档中提到的 `GAME_CATEGORIES` 变量与 `config/games.yaml` 配置文件均已废弃删除,
> 不存在游戏别名、队伍人数等独立配置——本文以当前代码为准。

## 配置方式

### 1. 获取频道/分类 ID

1. **启用开发者模式**:Discord 设置 → 高级 → 开启"开发者模式"
2. **获取 ID**:右键点击文字频道或分类名称 → "复制ID"

每个游戏需要两个 ID:

- **文字频道 ID**:机器人监听寻组消息的频道
- **语音分类 ID**:临时语音频道创建到哪个分类下

### 2. 环境变量配置

在 `.env` 中配置(格式:`游戏名:文字频道ID:语音分类ID`,英文逗号分隔):

```bash
CHANNEL_MAPPINGS=lol:1382775039870505051:1382731739754926090,Valorant:1382775114462138388:1382746935663792220

# 找不到匹配时的兜底(推荐设置)
DEFAULT_TEXT_CHANNEL_ID=1382776024542085331
DEFAULT_CATEGORY_ID=1382747423339839570
```

修改后重启机器人生效。

## 工作原理

1. 用户在某个**被监听的文字频道**发送寻组消息(如 `4=1`)
2. 机器人按「消息发在哪个频道」查 `CHANNEL_MAPPINGS` 确定游戏名和语音分类
   —— **不做游戏名别名匹配**,游戏名只用于生成频道名称(如 `lol-用户名`)
3. 在对应语音分类下创建临时频道,满员/超时后自动清理

## 添加新游戏

在 `CHANNEL_MAPPINGS` 末尾追加一段即可:

```bash
CHANNEL_MAPPINGS=...原有内容...,我的游戏:新文字频道ID:新语音分类ID
```

注意事项:

- 先在 Discord 里建好文字频道和语音分类,再填 ID
- 游戏名可用中英文,会直接出现在语音频道名里
- 修改后需重启机器人;启动日志会打印"解析到 N 个频道映射",核对数量即可确认生效

## 验证与排查

启动后日志会逐条验证映射:

```text
验证频道映射 1: 1382775039870505051 -> 1382731739754926090 (lol)
文字频道验证成功: ...
语音分类验证成功: ...
```

如果某条显示"不存在或无法访问",检查 ID 是否复制错、机器人是否有该频道的查看权限。
