1. `tournament_lol` — 锦标赛信息表
2. `tournament_lol_teams` — 参赛队伍表
3. `tournament_lol_team_members` — 队伍成员表
4. `tournament_lol_groups` — 分组表
5. `tournament_lol_matches` — 对战表

| 指令                              | 权限   | 描述                                                         |
| --------------------------------- | ------ | ------------------------------------------------------------ |
| `/tournament_lol create`          | 管理员 | 创建锦标赛                                                   |

| `/tournament_lol status`          | 所有人 | 查看当前比赛进度                                             |
