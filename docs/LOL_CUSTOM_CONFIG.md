# LOL 内战配置指南

## 📋 配置概述

LOL内战功能提供了灵活的配置选项，允许你精确控制：
- 哪些频道可以使用内战功能
- 语音频道的分类和组织
- 频道清理策略
- 功能的启用/禁用

## 🛠️ 基础配置

### 1. 启用LOL内战功能

在 `.env` 文件中设置：

```env
# 启用LOL内战功能
LOL_CUSTOM_ENABLED=true
```

**重要**: 如果设置为 `false` 或未设置，LOL内战功能将完全禁用。

### 2. 获取Discord频道ID

配置前需要获取Discord频道和分类的ID：

1. **启用开发者模式**：
   - 打开Discord用户设置 → 高级 → 开发者模式 ✅

2. **获取频道ID**：
   - 右键点击频道名称 → 复制频道ID

3. **获取分类ID**：
   - 右键点击分类名称 → 复制分类ID

## 🎯 监听频道配置

### 配置允许使用的频道

```env
# 只允许特定频道使用LOL内战功能
LOL_CUSTOM_CHANNEL_IDS=1234567890123456789,9876543210987654321

# 或者留空允许所有频道
LOL_CUSTOM_CHANNEL_IDS=
```

### 配置方案对比

| 配置方案 | 示例 | 适用场景 |
|---------|------|----------|
| **特定频道** | `LOL_CUSTOM_CHANNEL_IDS=123456,789012` | 专门的内战频道 |
| **多个频道** | `LOL_CUSTOM_CHANNEL_IDS=123456,789012,456789` | 不同区域/游戏分区 |
| **所有频道** | `LOL_CUSTOM_CHANNEL_IDS=` | 小型服务器 |

### 推荐配置

**方案A: 专用内战频道**
```env
LOL_CUSTOM_CHANNEL_IDS=1382747423339839570
```
- ✅ 专门的内战频道，不干扰其他聊天
- ✅ 便于管理和统计
- ❌ 需要用户切换频道

**方案B: 游戏分区频道**
```env
LOL_CUSTOM_CHANNEL_IDS=1382731739754926090,1382747262509121679
```
- ✅ 在游戏专门频道中发起内战
- ✅ 上下文相关性强
- ❌ 可能与游戏讨论混杂

## ⏰ 清理时间配置

### 基础配置

```env
# 内战结束后30分钟自动清理语音频道
LOL_CUSTOM_CLEANUP_DELAY=30m
```

### 时间设置参考

| 设置值 | 说明 | 适用场景 |
|--------|------|----------|
| `5m` | 5分钟 | 测试环境 |
| `15m` | 15分钟 | 快节奏内战 |
| `30m` | 30分钟 | **推荐设置** |
| `1h` | 1小时 | 长时间讨论 |
| `2h` | 2小时 | 复盘分析 |

## 📋 完整配置示例

### 示例1: 专业电竞服务器

## 🚨 常见配置问题

### 问题1: "LOL内战功能未启用"

**原因**: `LOL_CUSTOM_ENABLED` 未设置为 `true`

**解决**:
```env
LOL_CUSTOM_ENABLED=true
```

### 问题2: "当前频道不允许使用LOL内战功能"

**原因**: 频道ID不在允许列表中

**解决**:
1. 检查频道ID是否正确
2. 确认 `LOL_CUSTOM_CHANNEL_IDS` 配置
3. 或设置为空允许所有频道

### 问题3: 语音频道创建在错误位置

**原因**: 分类ID配置错误

**解决**:
1. 重新获取正确的分类ID
2. 更新 `LOL_CUSTOM_CATEGORY_ID`
3. 确保机器人有该分类的权限

### 问题4: 语音频道没有自动清理

**原因**: 清理延迟时间格式错误

**解决**:
```env
# 正确格式
LOL_CUSTOM_CLEANUP_DELAY=30m

# 错误格式
LOL_CUSTOM_CLEANUP_DELAY="30 minutes"
```

## 🎯 最佳实践建议

1. **开始时保守配置**：先限制到1-2个频道测试
2. **专用分类**：为内战创建专门的语音分类
3. **合理清理时间**：30分钟是大多数情况的最佳选择
4. **权限管理**：确保机器人有足够的频道管理权限
5. **用户指导**：在允许的频道置顶说明如何使用内战功能
